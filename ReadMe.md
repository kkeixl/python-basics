Калькулятор покупок зі знижками

1. Опис програми

Калькулятор покупок зі знижками — це проста консольна програма, створена мовою Python. Вона дозволяє розрахувати вартість покупки та автоматично визначити знижку.

2. Основні можливості програми

Введення імені покупця.

Введення назви товару.

Введення ціни та кількості товару.

Розрахунок загальної вартості покупки.

Автоматичне нарахування знижки.

Перевірка правильності введених даних.

Вибір способу оплати.

Виведення чека з результатами покупки.

3. Використані технології

Python 3.14

PyCharm

Git

GitHub

4. Використані конструкції Python

Під час створення програми були використані:

Змінні та константи.

Типи даних int, float, str, bool.

Функції input() та print().

Перетворення типів int() та float().

Форматування тексту за допомогою f-рядків.

Математичні операції.

Оператори порівняння та логічні оператори.

Умови if, elif, else.

Вкладені умови.

Умовні вирази.

Конструкція match-case.

Коментарі та відступи.

5. Інструкція із запуску

Встановити Python.

Відкрити проєкт у PyCharm.

Відкрити файл main.py.

Натиснути Shift + F10.

Ввести необхідні дані в консоль.

6. Приклад роботи програми

Введіть своє ім'я: Владислав

Введіть назву товару: Навушники

Введіть ціну товару: 1200

Введіть кількість товару: 1

Загальна сума: 1200 грн

Вам надано знижку 10%

Знижка: 120 грн

До сплати: 1080 грн
